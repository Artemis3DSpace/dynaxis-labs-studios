# Objective

Deliver Project Policy and Resource Inheritance for Phase 7C. The result must be directly usable by the next assigned coding agent without requiring that agent to invent architecture, schema semantics, service boundaries, or security rules.

# Context

Dynaxis owns Projects, Jobs, Assets, identity, graph, memory, orchestration, and verification. This Work Package is intentionally narrow: it must deliver Project Policy and Resource Inheritance without reinterpreting the roadmap or absorbing adjacent package scope.

- Developer Platform API credentials
- another Project entity
- Better Auth replacement

# Required Deliverables

- project policy layer consuming project membership service
- resource inheritance resolver from Project to Assets, Generations, Jobs, Characters, Products, Brands, Campaigns, and Design resources
- structured authorization errors for not found vs forbidden where safe
- Project roles map to project permissions; workspace owner/admin may administer workspace but must still pass defined project/resource rules
- Do not flatten `organization_id` onto every project child; infer child authorization through the canonical Project
- Preserve legacy compatibility only through explicit AuthContext compatibility paths

# Contracts That Must Not Change

- Dynaxis Project remains the canonical Project; do not create another Project entity.
- Better Auth remains the workspace authentication and organization-membership primitive.
- Provider credentials, model accounts, and worker adapters must not become user identity.
- Dynaxis Jobs, permissions, Project ownership, provenance, and verification gates must not be bypassed.
- Marketplace, App Factory, Skills, and Plugin work must use canonical registries instead of duplicating them.

# Acceptance Criteria

- A child resource authorization decision is derived from its canonical Project relationship.
- A user in the workspace but not the project is denied project-scoped editor actions unless policy explicitly grants workspace-admin override.

# Validation

- role matrix for owner/admin/editor/viewer
- resource inheritance tests for representative child domains
- Run `npm run program:status` when Work Package metadata changes.
- Run `git diff --check` before handoff.
