# Objective

Job State Machine Specification for Phase 7E Server Job / Event Engine. This package is scoped for roughly 1-3 focused engineering days and must preserve the canonical Dynaxis architecture.

# Context

Dynaxis owns Projects, Jobs, Assets, identity, graph, memory, orchestration, and verification. Providers and workers are adapters. Use the existing Phase 1-6I and Phase 7B/7C foundations as the implementation boundary.
