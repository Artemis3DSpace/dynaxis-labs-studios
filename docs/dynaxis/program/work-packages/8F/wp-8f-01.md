# Objective

Public API v1 and OpenAPI Contract for Phase 8F Developer Platform. This package is scoped for roughly 1-3 focused engineering days and must preserve the canonical Dynaxis architecture.

# Context

Dynaxis owns Projects, Jobs, Assets, identity, graph, memory, orchestration, and verification. Providers and workers are adapters. Use the existing Phase 1-6I and Phase 7B/7C foundations as the implementation boundary.

# Forbidden Paths

- lib/**, app/**, packages/**, and drizzle/** outside this package scope
- Provider API credentials as developer identity
- Marketplace commerce implementation
- bypassing Project/Job permissions

# Required Deliverables

- A production-grade specification deliverable for Public API v1 and OpenAPI Contract.
- Dependency, migration ownership, and validation evidence recorded in the final report.
- No implementation outside this Work Package scope.

# Contracts That Must Not Change

- Do not create another Dynaxis Project model.
- Do not replace Better Auth or couple provider credentials to user identity.
- Do not bypass Dynaxis Jobs, permissions, Project ownership, provenance, or verification gates.
- Do not duplicate canonical registries for Marketplace or App Factory.

# Acceptance Criteria

- Scope is implemented or specified only within the allowed paths.
- Dependencies are integrated before implementation begins unless this package is specification-only.
- Migration ownership is respected and no fixed future Drizzle migration number is reserved.
- Public contracts and compatibility seams are documented when they change.

# Validation

- Run targeted unit/integration tests for changed services or UI.
- Run `npm run program:status` when Work Package metadata changes.
- Run `git diff --check` before handoff.

# Commit

Use a scoped commit message beginning with `docs(dynaxis)`, `feat(dynaxis)`, `fix(dynaxis)`, or `test(dynaxis)` as appropriate for the package.

# Stop Condition

Stop when the listed deliverables and validation are complete. If a dependency, ownership conflict, security concern, or architecture contradiction appears, stop and report it instead of broadening scope.
