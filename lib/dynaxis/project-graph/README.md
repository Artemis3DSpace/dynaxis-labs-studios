# Dynaxis Project Graph Scaffold (Phase 7F)

This module is a pure domain-contract scaffold for WP-7F-01.

Includes only:

- node kind vocabulary
- edge kind taxonomy
- memory and decision record contracts
- graph relationship naming rules
- validation helpers

Out of scope in this scaffold:

- persistence and query services (WP-7F-02+)
- migrations or schema changes
- worker/runtime execution
