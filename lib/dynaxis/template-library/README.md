# Template Library Scaffold

This directory contains the scaffold-only contract layer for reusable template,
blueprint, and app-pack metadata in Dynaxis.

## Included

- template metadata contract
- blueprint package metadata contract
- app pack contract
- capability reference contract
- design-system and layout compatibility contracts
- license and usage metadata contract
- searchable library index and search filter contracts
- validation helpers and schema exports

## Explicitly Excluded

- marketplace implementation
- persistence, schema, drizzle, or migrations
- package publishing workflows
- app generation or repository generation
- deployment and external API behavior
- provider connection or secret integrations

All modules are contract-only and side-effect free.
