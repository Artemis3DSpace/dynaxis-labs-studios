# Dynaxis Capabilities Scaffold (Phase 7G)

This module is a pure domain-contract scaffold for WP-7G-01.

Includes only:

- capability category taxonomy
- model domain taxonomy
- provider/model mapping contract placeholder
- cost/latency/quality metadata contract placeholder
- resolver decision contract placeholder

Out of scope in this scaffold:

- registry schema or migrations (WP-7G-02+)
- model routing/runtime selection implementation
- external provider API calls
